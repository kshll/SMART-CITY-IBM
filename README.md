# Smart City Management System 🏙️

A web-based Smart City application developed as part of an IBM project, focusing on modern frontend technologies and scalable architecture.

## 🎯 Overview

Smart City Management System is a comprehensive platform for managing urban infrastructure and services. It provides a responsive, modern interface built with cutting-edge frontend technologies to handle complex city management operations.

## ✨ Features

- 🌐 Responsive UI using Tailwind CSS
- ⚡ Fast build and development with Vite
- 🔒 Type-safe development with TypeScript
- 📱 Mobile-first responsive design
- 🎨 Modern UI components
- 🚀 Optimized performance

## 🛠 Tech Stack

- **TypeScript** – Type-safe JavaScript
- **Vite** – Next-generation build tool
- **Tailwind CSS** – Utility-first CSS framework
- **Node.js** – Runtime environment
- **HTML5** – Semantic markup

## 🚀 Getting Started

### Prerequisites

- Node.js 16+ 
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/kshll/SMART-CITY-MANAGEMENT.git
cd SMART-CITY-MANAGEMENT
```

2. Install dependencies:
```bash
npm install
```

### Development

Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:5173`

### Production Build

Build for production:
```bash
npm run build
```

## 📋 Available Scripts

- `npm run dev` – Start development server
- `npm run build` – Build for production
- `npm run preview` – Preview production build
